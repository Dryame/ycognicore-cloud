# ADR-013 : Alternative pgsty/minio pour l'image MinIO

## Statut
Accepté — 30/09/2026

## Contexte
MinIO a retiré ses images Docker de l'édition communautaire en 2025.
Pull impossible depuis :
- docker.io/minio/minio (pull access denied)
- quay.io/minio/minio (401 UNAUTHORIZED)
- bitnami/minio (not found)

Le plan initial (Chainguard) était bloqué par une vérification manuelle
de 24-48h incompatible avec la clôture de H0.

## Décision
Utiliser pgsty/minio (fork communautaire actif sur Docker Hub).

## Justification
1. API 100% compatible S3 (même base de code MinIO)
2. Aucune inscription requise (pull direct)
3. Mise à jour régulière
4. Migration possible vers Chainguard plus tard sans changement de code

## Conséquences

### Positives
- Infrastructure opérationnelle immédiatement
- API S3 standard respectée
- Pas de dépendance à un compte Cloud

### Négatives
- Dépendance à un mainteneur communautaire unique
- Moins officiel que MinIO Inc.

## Action future (Phase 3)
Si Chainguard est validé :
- Changer l'image dans docker-compose.yml (1 ligne)
- Migrer les données via boto3 (script fourni)
