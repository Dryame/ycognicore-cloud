# ADR-008 : Choix de Spring Boot 4

## Statut
Accepté — 30/09/2026

## Contexte
Deux options sont disponibles pour le backend :
- **Spring Boot 3.5 LTS** (Long Term Support, 2024-2029)
- **Spring Boot 4.0** (dernière version, 2026)

Le rapport 04-78 retenait initialement « Spring Boot 3 ». Mais le projet
a démarré avec Spring Boot 4.1.1 (cf. rapport 07-78).

Points à considérer :
- Compatibilité de Spring Cloud avec Boot 4
- Compatibilité de Spring Security 7 (RBAC, JWT, MFA)
- Compatibilité d'Hibernate 7 (multi-tenant)
- Support à long terme (5 ans minimum)

## Décision
Adopter **Spring Boot 4** (dernière version stable).

## Justification
1. Version déjà en place dans le projet (rapport 07-78)
2. Spring Cloud 2026.0 est compatible Boot 4
3. Spring Security 7 supporte les patterns RBAC/MFA nécessaires
4. Hibernate 7 supporte le multi-tenant natif (ADR-006)
5. Le support LTS dure jusqu'en 2031

## Conséquences

### Positives
- Cohérence avec l'existant (aucun downgrade nécessaire)
- Support à long terme jusqu'en 2031
- APIs modernes (records, virtual threads, native images)

### Négatives
- Documentation francophone moins fournie sur Boot 4
- Certaines bibliothèques tierces peuvent ne pas être à jour
- Migration depuis des exemples Boot 3 requiert adaptations

## Alternatives rejetées
- **Spring Boot 3.5 LTS** : rejeté car downgrade inutile
- **Spring Boot 5 (pas encore sorti)** : rejeté car instable
