# ADR-023 : Découpage en 7 modules métier

- **Statut** : Accepté
- **Date** : 06/10/2026
- **Domaine** : Architecture

## Contexte
La Phase 2 doit concevoir ~75 tables métier. Il faut décider comment organiser cette masse.

## Décision
Découper la Phase 2 en 7 modules : CRM, Ventes, Achats, Stocks, Comptabilité, Trésorerie, Projets.

## Justifications
- Couverture du cycle de vie complet d'une entreprise
- Correspond aux standards ERP (SAP, Odoo)
- Chaque module = 7 à 15 tables (taille gérable)
- Flux naturel : CRM → Ventes → Achats → Stocks → Compta → Trésorerie
- Module Comptabilité dédié SYSCOHADA BF

## Conséquences
- Positives : conception indépendante, ordre clair, modules réutilisables
- Négatives : discipline stricte sur les FK inter-modules

## Alternatives rejetées
- Module monolithique (75 tables ingérables)
- Découpage par type de données (non métier)
