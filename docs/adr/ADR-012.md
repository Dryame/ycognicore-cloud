# ADR-012 : Healthcheck Docker avec 127.0.0.1 au lieu de localhost

## Statut
Accepté — 30/09/2026

## Contexte
Le healthcheck Docker de Vault échouait systématiquement avec :
    wget: can't connect to remote host: Connection refused

Alors que l'API Vault répondait parfaitement à :
    curl http://localhost:8200/v1/sys/health

## Cause racine
Dans un conteneur Docker, localhost est résolu en premier en IPv6
(::1) puis en IPv4 (127.0.0.1). Vault n'écoute que sur IPv4 (0.0.0.0),
pas sur IPv6. wget essaie ::1, échoue, ne bascule pas en IPv4.

## Décision
Utiliser systématiquement 127.0.0.1 au lieu de localhost dans les
healthchecks Docker.

## Conséquences

### Positives
- Healthcheck Vault fonctionne (unhealthy → healthy)
- Règle applicable à tous les futurs healthchecks
- Aucun impact sur les autres services

### Négatives
- Légère perte de lisibilité (IP numérique)

## Règle générale
Dans tous les healthchecks Docker :
    INTERDIT  : http://localhost:PORT/...
    RECOMMANDE: http://127.0.0.1:PORT/...
