# ADR-025 : 27 types ENUM PostgreSQL

- **Statut** : Accepté
- **Date** : 06/10/2026
- **Domaine** : Base de données

## Contexte
Les tables ont besoin de statuts (BROUILLON, ENVOYE, PAYE, etc.). Choisir l'implémentation.

## Décision
Utiliser des ENUMs PostgreSQL : 27 ENUMs répartis sur les 7 modules.

## Justifications
- Intégrité stricte au niveau BDD
- Performance (4 octets vs VARCHAR)
- Autocomplétion IDE
- Documentation intégrée
- Sécurité (pas d'injection)

## Conséquences
- Positives : impossible de stocker une valeur invalide
- Négatives : ALTER TYPE bloquant pour modifications futures

## Alternatives rejetées
- VARCHAR libre (aucune intégrité)
- Table de référence (surdimensionné)
