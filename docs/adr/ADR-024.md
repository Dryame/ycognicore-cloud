# ADR-024 : Conventions transversales obligatoires

- **Statut** : Accepté
- **Date** : 06/10/2026
- **Domaine** : Base de données

## Contexte
Les ~75 tables vont être conçues sur plusieurs semaines. Risque d'incohérence maximal.

## Décision
Appliquer 10 conventions à toutes les tables métier :
1. Clé primaire UUID
2. Audit temporel (date_creation, date_maj, date_suppression)
3. Traçabilité utilisateur (created_by, updated_by)
4. Multi-tenant transparent (aucun tenant_id)
5. Clés étrangères RESTRICT par défaut
6. Numérotation légale via prochain_numero()
7. Statuts via ENUM PostgreSQL
8. Nommage snake_case
9. Contraintes CHECK obligatoires
10. Index sur FK + colonnes de recherche

## Justifications
- Cohérence sur les 75 tables
- Développeurs autonomes
- Refactoring facilité

## Conséquences
- Positives : uniformité, maintenabilité
- Négatives : discipline stricte requise
