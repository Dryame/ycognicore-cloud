# ADR-010 : Configuration Flyway explicite pour Spring Boot 4

## Statut
Accepté — 30/09/2026

## Contexte
Spring Boot 4 a modularisé ses starters. Il n'existe plus de starter
`spring-boot-starter-flyway`. L'ajout des dépendances `flyway-core` et
`flyway-database-postgresql` ne suffit pas à déclencher l'auto-configuration.

Symptôme : Spring Boot démarre, HikariCP et Hibernate s'initialisent,
mais Flyway ne s'exécute pas (aucune ligne dans les logs).

## Décision
Créer un bean `Flyway` explicite dans `FlywayConfig.java`.

## Justification
1. Contourne la lacune de Boot 4 sans downgrade
2. Utilise l'API Flyway native
3. Contrôle total sur les options (baseline, validate, clean)
4. Compatible avec les futures versions de Boot 4.x

## Conséquences

### Positives
- Flyway opérationnel (6 migrations appliquées avec succès)
- Contrôle explicite des options
- Indépendant des évolutions de l'auto-config Boot

### Négatives
- Code de configuration supplémentaire (~60 lignes)
- Maintenance manuelle des paramètres
