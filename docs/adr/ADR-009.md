# ADR-009 : Choix d'Angular 22 LTS

## Statut
Accepté — 30/09/2026

## Contexte
Le rapport 04-78 retenait « Angular 17+ ». Le projet a démarré avec
Angular 22.2.0 (cf. rapport 08-78).

Points à considérer :
- Compatibilité de PrimeNG avec Angular 22
- Disponibilité des composants UI métier (DataTable, Calendar, Charts)
- Support LTS d'Angular
- Support des Signals (nouveauté Angular 17+)

## Décision
Adopter **Angular 22 LTS** (dernière version LTS).

## Justification
1. Version déjà en place dans le projet (rapport 08-78)
2. Angular 22 est une **LTS** (support 18 mois minimum)
3. Signals stables depuis Angular 17 — utilisés pour la réactivité
4. PrimeNG 18+ supporte Angular 22 (à vérifier à l'intégration)
5. Nouveau compilateur (Vite) plus rapide

## Conséquences

### Positives
- Cohérence avec l'existant
- Support LTS jusqu'à fin 2027
- Signals + Standalone Components : code moderne
- Meilleure performance (Vite)

### Négatives
- PrimeNG peut accuser un léger retard sur les nouvelles versions Angular
- Documentation francophone limitée sur Angular 22
- Nécessite Node.js 22+ (déjà installé)

## Alternatives rejetées
- **Angular 20 LTS** : rejeté car downgrade inutile
- **Vue 3** : rejeté (04-78 retient Angular)
- **React** : rejeté (04-78 retient Angular)
