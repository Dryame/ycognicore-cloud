# ADR-027 : Soft delete obligatoire

- **Statut** : Accepté
- **Date** : 06/10/2026
- **Domaine** : Base de données

## Contexte
La suppression définitive peut violer NFR-SEC-32 (droit à l'oubli) et NFR-CONF-04 (conservation 10 ans).

## Décision
Soft delete obligatoire :
- Colonne date_suppression TIMESTAMPTZ
- NULL = actif, non-NULL = supprimé
- Trigger empecher_suppression_physique() interdit DELETE

## Justifications
- Traçabilité et audit fiscal (10 ans)
- Récupération possible
- Intégrité des FK

## Conséquences
- Positives : aucune perte de données, conformité légale
- Négatives : filtrer par date_suppression IS NULL partout
