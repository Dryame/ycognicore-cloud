# ADR-026 : Ordre de conception par dépendances

- **Statut** : Accepté
- **Date** : 06/10/2026
- **Domaine** : Méthodologie

## Contexte
Les 7 modules ont 14 relations croisées. Concevoir dans le mauvais ordre force à refactoriser.

## Décision
Concevoir dans l'ordre du graphe de dépendances :
- J1 : CRM → Ventes
- J2 : Achats → Stocks
- J3 : Comptabilité → Trésorerie → Projets

## Justifications
- Zéro refactorisation (FK pointent vers tables définies)
- Fondations stables (CRM définit clients)
- Hub central en dernier (Comptabilité)

## Conséquences
- Positives : aucune table à refaire, testabilité immédiate
- Négatives : ordre imposé, Comptabilité tardive
