Politique de confidentialité

Dernière mise à jour : {{ derniereMaj }}

1. Données collectées

Lors de chaque connexion, les informations suivantes sont enregistrées afin d'assurer la sécurité de votre compte :

  • Adresse IP
  • Type de navigateur et système d'exploitation
  • Date et heure de connexion
  • Localisation approximative (pays et ville) déduite de l'adresse IP

2. Utilisation

Ces données servent uniquement à :

  • détecter les connexions inhabituelles ;
  • prévenir les accès non autorisés ;
  • vous informer des activités sur votre compte.

3. Localisation approximative

La localisation est limitée à un niveau pays et ville. Aucune position précise n'est collectée. La résolution est effectuée localement, sans envoi de votre adresse IP à un service tiers.

4. Conservation

Les données de connexion sont conservées {{ dureeConservation }} par défaut. Cette durée est paramétrable par votre entreprise (entre 7 et 90 jours).

5. Accès

Seuls les administrateurs autorisés de votre entreprise peuvent consulter l'historique de vos connexions.

6. Vos droits

Conformément à la {{ referenceLegale }}, vous disposez d'un droit d'accès, de rectification et d'opposition. Contactez votre administrateur pour exercer ces droits.
